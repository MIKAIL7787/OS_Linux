# Скрипты на Bash

```console
ali@Sapphire:~> ./myscript
bash: ./myscript: Permission denied
ali@Sapphire:~> chmod +x ./myscript
ali@Sapphire:~> ./myscript
/home/ali
ali
```

```bash
#!/bin/bash
IFS=:
for folder in \$PATH
do
    echo "\$folder:"
    for file in \$folder/*
    do
        if [ -x "\$file" ]
        then
            echo "    \$file"
        fi
    done
done
```

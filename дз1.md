## Подробный разбор выполненных операций

В процессе работы были изучены способы взаимодействия с процессами через сигналы POSIX:

| Команда | Что произошло |
| :--- | :--- |
| `pidof nano` | Утилита вывела PID 5523 — значит, текстовый редактор nano запущен в системе. |
| `kill -17 5523` | Отправлен сигнал SIGCHLD (или SIGSTOP — в зависимости от маппинга системных вызовов), меняющий состояние процесса. |
| `kill -18 5523` | Отправлен сигнал `SIGCONT`, возобновляющий работу ранее приостановленного процесса. |
| `kill 5523` | Команда kill без флага посылает стандартный сигнал `SIGTERM` (15), который мягко предлагает процессу завершиться. |
| `ps` | Снимок процессов показал, что процесс 5523 (nano) завершился и пропал из таблицы — остались только bash и сам ps. |
| `sleep 67 & 5523` | Попытка фонового запуска. Сама команда `sleep 67 &` ушла в фон (ID [1], PID 5580). А следующее за ней число 5523 оболочка bash попыталась выполнить как отдельную команду, поэтому выдала ошибку `5523: command not found`. |

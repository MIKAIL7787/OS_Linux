# Операционные системы и среды

Добро пожаловать на курс «Операционные системы и среды»! Здесь вы познакомитесь с операционной системой как средой выполнения программ и освоите практические навыки работы с Linux Server.

## О курсе

Курс построен по принципу «от понимания к практике»: каждая тема сопровождается практическими заданиями и единым сквозным сценарием. Все материалы, конспекты и результаты практик ведутся в едином Git-репозитории — это ваша рабочая среда на весь семестр.

## Как устроена работа

- **Единый репозиторий.** Все материалы, заметки и результаты практик ведутся в одном Git-репозитории. Ведение истории коммитов — часть курса.
- **Сквозная практика.** Темы связаны между собой: настройки, сделанные в начале курса, используются в последующих заданиях.


## Устройство репозитория

Репозиторий разделён на 4 папки: домашки, самостоятельные, теория и экзамен. В папке домашки для каждой домашней работы выделена своя подпапка с самим выполненным заданием и README файлом.

## Шаг 1. Создание пользователей и группы

На первом этапе создаём новую группу devteam и трёх пользователей: user1, user2 и user3. Для каждого задаём пароль.

### Выполняемые команды:
```bash
# 1. Создание группы devteam
sudo groupadd devteam

# 2. Создание трёх пользователей с домашними директориями (-m)
sudo useradd -m user1
sudo useradd -m user2
sudo useradd -m user3

# 3. Установка паролей для созданных пользователей
sudo passwd user1
sudo passwd user2
sudo passwd user3

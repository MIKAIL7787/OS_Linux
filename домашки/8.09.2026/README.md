1. **Создание пользователей:** Командой `sudo adduser --gecos "" --disabled-password` создаются три пользователя: `user1`, `user2` и `user3`. У них нет паролей (отключены), а дополнительные данные не запрашиваются.
2. **Создание файлов:** С помощью `sudo -u` от имени каждого из новых пользователей в их домашних директориях создаются текстовые файлы:
   * `user1` создает `/home/user1/file1.txt`
   * `user2` создает `/home/user2/file2.txt`
   * `user3` создает `/home/user3/file3.txt`
3. **Смена владельца файлов (chown):** Выполняется перекрестная смена владельцев файлов. Командой `chown` файл, созданный первым пользователем, передается второму, второй — третьему, а третий — первому:
   * Владельцем `file1.txt` становится `user2`
   * Владельцем `file2.txt` становится `user3`
   * Владельцем `file3.txt` становится `user1`
